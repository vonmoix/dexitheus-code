## Shared base

All experiments load [`base.css`](./base.css) before their own styles: design tokens (mustard `#ECB617`, black, spacing, type), fonts and the common pieces of every page (stage, label, credit, buttons, dark theme with `class="dx-dark"` on `<html>`). Change a colour there and every experiment follows.

On CodePen the same file lives in a pen of its own, [xbqMxyq](https://codepen.io/dexitheus/pen/xbqMxyq), linked from each pen under Settings → CSS. If you copy a single experiment, take `base.css` with it.

Follow along on [Instagram](https://www.instagram.com/dexitheus.ai/) and [CodePen](https://codepen.io/dexitheus).
