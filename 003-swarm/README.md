# Exp. 003 · Swarm

![Poster](./poster.jpg)

A particle swarm drawn on a plain 2D canvas, no libraries. Particles drift and link up when they get close; move the pointer to push them away and click or tap to add more.

- Live demo and notes: https://dexitheus.ai/experimentos/003-swarm/
- CodePen: https://codepen.io/dexitheus/pen/bOzbpo
- Category: Canvas

Open `index.html` in a browser. Files: index.html, style.css, script.js, plus the shared [`base.css`](../base.css) one folder up.
