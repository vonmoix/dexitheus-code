# Exp. 017 · News slider

A card slider built on native scroll-snap, no libraries. A black panel glides behind the card you hover or focus, and each card carries a Swiss-style poster generated with AI (Magnific). Arrows, dots and keyboard navigation included.

Based on the news card slider by [Muhammed Erdem](https://codepen.io/muhammederdem).

- Live demo and notes: https://dexitheus.ai/experimentos/017-news-slider/
- CodePen: https://codepen.io/dexitheus/pen/JjeWqbM
- Category: Components

Open `index.html` in a browser. Files: index.html, style.css, script.js, plus the shared [`base.css`](../base.css) one folder up.
