# Exp. 007 · Five flavours

![Poster](./poster.jpg)

Responsive menu where every tab has its own Bauhaus colour: a thin strip at rest that opens into a flat colour block (crimson, blueprint, tangerine, flamingo, herbs) on the mustard page. A horizontal bar on desktop, a vertical list on mobile.

- Live demo and notes: https://dexitheus.ai/experimentos/007-five-flavours/
- CodePen: https://codepen.io/dexitheus/pen/BVboQv
- Category: Components

Open `index.html` in a browser. Files: index.html, style.css, plus the shared [`base.css`](../base.css) one folder up.
