# Exp. 011 · Badges

Icon buttons with red notification badges. Counts above 99 show as 99+; click a button to clear its badge. Icons from Material Symbols Sharp.

Based on [this shot](http://drbl.in/koLf) by Ced Funches.

- Live demo and notes: https://dexitheus.ai/experimentos/011-badges/
- CodePen: https://codepen.io/dexitheus/pen/dyQWRdb
- Category: Components

Open `index.html` in a browser. Files: index.html, style.css, script.js, plus the shared [`base.css`](../base.css) one folder up.
