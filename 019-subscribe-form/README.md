# Exp. 019 · Subscribe form

A subscribe form that sweeps shut and slides in a thank-you. A real form underneath: native email validation, a live status for screen readers and a fade-only version for reduced motion.

Inspired by Niklaus Gerber's Daily UI 026.

- Live demo and notes: https://dexitheus.ai/experimentos/019-subscribe-form/
- CodePen: https://codepen.io/dexitheus/pen/dEdeNX
- Category: Components

Open `index.html` in a browser. Files: index.html, style.css, script.js, plus the shared [`base.css`](../base.css) one folder up.
